# ADR-0004: 人类确认后直接归档

## Decision

Dashboard 的单条归档、批量归档、审阅删除和信件删除只保留一次确认弹框。确认后立即执行，不要求填写理由、不提交 AI 审批，也不受旧审批申请次数限制。

所有人类 Web 删除入口共用 `execute_confirmed()`，沿用 `HumanDeleteExecutor` 的软删除与信件派生索引清理。普通归档入口仍调用 `bucket_mgr.delete()`：文件移入 `archive/`，写入 `deleted_at`，退出活跃浮现和搜索；不会物理抹除文件。认证与 DELETE 的 `confirm=true` 检查继续保留。

批量操作逐项执行并返回成功、缺失和失败列表。成功删除时，同一记忆遗留的待审批申请标记为 superseded；执行失败时保留其原状态。历史审批存储与 AI 接口保留兼容，新的 Web 操作不再创建申请。AI 和自动衰减的生命周期行为不变。

## Rationale

此私人部署中，记忆管理的最终决定由使用者作出。一次明确确认足以表达意愿，额外的理由填写和 AI 审批增加了等待和重复操作。
